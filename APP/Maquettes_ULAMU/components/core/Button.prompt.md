Bouton principal d'Ulamu : 4 variantes, 3 tailles, grain sérigraphié et feedback au press (scale 0.97 / 80ms).

```jsx
<Button variant="primary" iconLeft="plus">Nouvelle consultation</Button>
<Button variant="secondary">Annuler</Button>
<Button variant="ghost" size="sm" iconLeft="filter">Filtrer</Button>
<Button variant="danger" iconLeft="trash">Supprimer</Button>
<Button loading>Paiement…</Button>
```

Variantes : `primary` (accent cobalt), `secondary` (surface muted + bord), `ghost` (transparent + bord subtil), `danger` (rouge). Props : `size` sm/md/lg, `iconLeft`/`iconRight` (noms d'icônes Ulamu), `fullWidth`, `loading`, `disabled`.
