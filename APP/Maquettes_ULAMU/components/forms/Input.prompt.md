Champ texte Ulamu (hauteur 36, focus ring cobalt). Icônes et état d'erreur intégrés.

```jsx
<Input placeholder="Rechercher un médecin…" leftIcon="search" />
<Input type="email" placeholder="adresse@exemple.cg" invalid />
<Input placeholder="Désactivé" disabled />
```

Props : `leftIcon`/`rightIcon` (icônes Ulamu), `invalid`, `disabled`, + tous les attributs `<input>`. Voir aussi `Textarea`, `Select`, `Checkbox`, `Radio`, `Switch`, `FormField`.
