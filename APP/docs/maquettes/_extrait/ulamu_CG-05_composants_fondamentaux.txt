 <!-- RULES -->
 
 
07 — Règles d'usage

 

 

 
Interdictions absolues

 
Dégradé sur bouton — couleur unie obligatoire
Supprimer le focus ring — jamais outline:none sans alternative accessible
Utiliser la couleur seule pour indiquer une erreur ou un succès
Placeholder comme substitut de label de champ
border-radius > 14px sur boutons (pas de pill généralisé)
Badges avec dégradé — fond rgba() uni uniquement
Avatar sans fallback initiales si l'image est absente
Tooltip avec z-index supérieur aux modales
 
 

 
Bonnes pratiques obligatoires

 
Grain ::after visible sur tous les boutons — identité visuelle Ulamu
Label toujours au-dessus du champ — jamais inline flottant
Message d'erreur avec icône + texte — jamais couleur seule
Focus ring 3px rgba(39,86,166,0.30) sur tous les éléments interactifs
Badges : fond semi-transparent + bordure harmonique
Avatars : initiales 1-2 lettres maj, police display, fond coloré
Toggle : transition .2s linear sur bg et position thumb
Séparateur tableau : border-subtle 1px — jamais fond coloré alterné
