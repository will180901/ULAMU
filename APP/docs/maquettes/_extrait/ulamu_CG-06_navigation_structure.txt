 <!-- RULES -->
 
 
07 — Règles d'usage

 

 

 
Interdictions absolues

 
 
Sidebar sans glassmorphism — toujours glass + grain

 
Nav item actif sans indicateur visuel clair (fond + couleur)

 
Breadcrumb sans lien cliquable sur les segments non-finaux

 
Plus de 3 styles de tabs différents dans la même interface

 
Pagination avec moins de 3 pages numérotées visibles

 
Menu contextuel sans ombre --shadow-lg — jamais plat

 
Topbar sans grain overlay — partie de l'identité visuelle

 
Topbar hors position sticky — toujours visible en scrollant

 
 

 
Bonnes pratiques obligatoires

 
 
Sidebar : section labels en monospace uppercase pour les groupes

 
Nav badge : pills accent pour les nouveaux éléments, warning si urgence

 
Breadcrumb : tronquer au milieu pour les chemins > 4 niveaux

 
Tabs underline : par défaut sur les pages principales (dossier, tableau de bord)

 
Tabs pills : pour les filtres temporels et les vues alternatives

 
Pagination : toujours afficher le total de résultats en info-texte

 
Menus contextuels : grouper les actions par thème avec separateur

 
Actions destructives : toujours en bas du menu, couleur danger, séparateur avant
