07 — Règles d'usage

Interdictions absolues
  • outline:none sur tout élément interactif sans alternative de focus visible
  • Utiliser la couleur seule pour indiquer un état error, warning ou success
  • Supprimer l'état hover sur les éléments interactifs — WCAG 1.4.11
  • Texte non-décoratif sous 3:1 de contraste — WCAG 1.4.3 minimum AA
  • Modale sans focus trap — le Tab doit cycler à l'intérieur uniquement
  • Toast sans role="status" ou role="alert" — lecteur d'écran ne l'annonce pas
  • Icônes SVG décoratives sans aria-hidden="true" — lues par les screen readers
  • Input sans label visible ou aria-label — le placeholder ne suffit pas
  • État disabled via opacity seule sur le fond — toujours cursor:not-allowed aussi
  • Tableau sans en-têtes <th scope> — navigation screen reader impossible
Bonnes pratiques obligatoires
  • Focus ring unifié sur tous les composants : outline 3px rgba(39,86,166,0.30) + offset 2px
  • Utiliser :focus-visible (pas :focus) pour éviter le ring au clic souris
  • Toujours combiner couleur + icône + texte pour les états sémantiques
  • Tester les ratios de contraste dans les deux thèmes avant validation
  • Implémenter focus trap dans toutes les modales et drawers
  • Retourner le focus sur l'élément déclencheur à la fermeture d'une modale
  • aria-live="polite" sur les toasts info/success · "assertive" sur les erreurs
  • aria-hidden="true" sur toutes les icônes SVG décoratives
  • Tester la navigation clavier complète sur chaque nouvelle page implémentée
  • Sur mobile : bottom navigation (4-5 items max) · modales en bottom sheets
