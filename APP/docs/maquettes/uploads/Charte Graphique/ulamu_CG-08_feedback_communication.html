06 — Règles d'usage

Interdictions absolues
  • Toast sans glass + grain — fond solide jamais autorisé sur toast
  • Toast positionné à gauche, à droite ou en bas — toujours top-center
  • Modale sans overlay sombre — toujours rgba(0,0,0,0.5)
  • Modale sans bouton de fermeture (×) explicite en haut à droite
  • Alert inline sans icône — couleur seule insuffisante pour l'accessibilité
  • Spinner sans arret — toujours une durée maximale définie
  • Empty state sans action — toujours proposer une sortie
  • Plusieurs modales ouvertes simultanément — jamais d'empilement
Bonnes pratiques obligatoires
  • Toasts : disparition auto 4s (info/success) · 6s (warning/error) · action prolonge
  • Modales : fermeture via Echap, clic overlay, ou bouton × explicite
  • Drawer : animation slide depuis la droite · 250ms linear
  • Alertes inline : avec titre + corps + icône + bouton de fermeture
  • Skeleton : reproduire fidèlement la structure du contenu final
  • Spinner sur bouton : remplace l'icône gauche, désactive le bouton
  • Progress bar : toujours accompagnée d'un pourcentage ou d'un label
  • Empty state : icône thématique + titre clair + description courte + CTA
