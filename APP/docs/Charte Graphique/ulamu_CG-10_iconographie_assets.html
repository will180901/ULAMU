04 — Règles couleur par contexte

currentColor héritée · jamais de couleur codée en dur hors tokens
Nouveau
Bouton primaire · Icon seule
stroke: white / #FFFFFF
Icône sur fond accent-500. Blanc pur — jamais de variante colorée. S'applique à tout fond coloré sombre.
Sidebar nav · Active vs idle
Active: --accent-500 (light) / --accent-300 (dark)
Idle: --text-tertiary
Différenciation claire active/idle via la couleur seule. Jamais de fill sur les icônes de nav idle.

L'icône reçoit la même couleur que le texte qui l'accompagne via currentColor. Cohérence garantie automatiquement.

État désactivé (disabled)
opacity: 0.4 sur le composant entier
Jamais de changement de couleur d'icône isolé. L'opacité 0.4 s'applique au conteneur entier — icône et texte ensemble.
outline: 3px solid

Bouton icône au focus clavier

L'icône elle-même ne change pas de couleur au focus. Seul le focus ring (outline) s'applique au conteneur. WCAG AA obligatoire.

Principes d'illustration fonctionnelle
Empty state — Dossiers
Outline monochrome (--text-tertiary) + élément accent pour l'action principale. Jamais de fill coloré en dehors du point focal.
Graphique — Area chart
Seul cas où le dégradé est autorisé. Couleur de courbe = accent-500. Fill opacity 0.18 → 0. Grilles en border-subtle.
Illustration sécurité RGPD
Structure en outline neutre (--text-tertiary) + fill accent très désaturé (opacity 0.07) + élément focal en accent-500 plein.

07 — Règles d'usage

Interdictions absolues
  • Utiliser un emoji, un caractère Unicode ou ASCII comme icône d'interface — jamais
  • Utiliser une bibliothèque d'icônes autre que Lucide Icons sans validation
  • Importer des icônes via font-icon (icon font) — SVG inline exclusivement
  • Hardcoder une couleur d'icône hors des tokens (ex: stroke="#2756A6" en dur)
  • Utiliser des icônes avec fill coloré hors contextes documentés (sémantiques uniquement)
  • Dépasser 24px pour une icône dans un composant UI courant
  • Utiliser stroke-width différent des 3 valeurs autorisées (1.4 / 1.5 / 2.0)
  • Inclure le logo mark sur fond transparent ou dégradé
  • Modifier les proportions du logo mark (pas de déformation)
  • Utiliser une icône fill (solide) pour un état idle — outline uniquement
Bonnes pratiques obligatoires
  • Toujours utiliser stroke="currentColor" — la couleur hérite du parent CSS
  • viewBox="0 0 16 16" sur toutes les icônes sans exception
  • stroke-linecap="round" + stroke-linejoin="round" sur toutes les icônes
  • Taille 16px (icon-md) par défaut — adapter uniquement avec justification
  • stroke-width 1.4 dans la sidebar/nav · 1.5 dans les boutons · 2.0 pour l'emphase
  • Icône active sidebar : couleur accent via CSS, jamais en attribut SVG
  • État disabled : opacity 0.4 sur le conteneur, jamais sur l'icône seule
  • Illustrations fonctionnelles : outline monochrome + seul élément focal en accent
  • Logo mark : fond accent-500 obligatoire, border-radius proportionnel à la taille
  • Tester chaque icône dans les deux thèmes — currentColor garantit la cohérence
