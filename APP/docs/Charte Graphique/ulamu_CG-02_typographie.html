Typographie

Système typographique complet d'Ulamu. Deux familles humanistes complémentaires, une échelle de 16 paliers, des tokens nommés et des règles d'usage précises par contexte — titres, corps, labels, captions, code. Aucune police utilisée dans l'interface ne doit être hors de ce référentiel.

01 — Familles de polices

Duo humaniste · Plus Jakarta Sans + Inter + JetBrains Mono
Display · Titres
Plus Jakarta Sans
Rôle : Tous les titres, headings, KPI metrics, logo, labels d'interface importants.

Pourquoi : Géométrie légère portée par des terminaisons humanistes — elle est expressive sans être froide. Ses poids 700/800 ont une présence mémorable aux petites tailles, parfaite pour les dashboards denses.

Corps · Labels · UI
Inter
Rôle : Corps de texte, descriptions, labels de formulaire, contenu de tableaux, métadonnées, hints.

Pourquoi : Optimisée pour les interfaces numériques, Inter offre une lisibilité irréprochable à toutes les tailles. Ses proportions neutres ne concurrencent pas Plus Jakarta Sans mais la complètent.

Mono · Code · Tokens
JetBrains Mono
Rôle : Valeurs de tokens dans les outils dev, codes d'ordonnances, identifiants patients, références système, valeurs numériques techniques.

Pourquoi : Ligatures de programmation intelligentes, lecture aisée des chiffres ambigus (0/O, 1/l). Discrétion parfaite dans l'interface tout en restant clairement distincte des deux autres familles.

06 — Règles d'usage

Obligations et interdictions absolues
Interdictions absolues
  • Utiliser Arial, Roboto, Helvetica ou toute police hors du système
  • Dépasser 40px pour les titres — jamais de taille "héroïque" surdimensionnée
  • Utiliser Plus Jakarta Sans pour le corps de texte long (lisibilité dégradée)
  • Utiliser Inter pour les grandes métriques KPI (impact insuffisant)
  • Mélanger plus de 2 familles visibles dans un même écran
  • Utiliser le poids 300 (Light) pour des éléments interactifs
  • Mettre du texte en ALL CAPS avec la famille Display sur plus de 3 mots
  • Appliquer letter-spacing négatif à Inter en dessous de 16px
  • Utiliser JetBrains Mono pour du texte courant ou des titres
Bonnes pratiques obligatoires
  • Toujours utiliser les tokens nommés — jamais de taille px codée en dur
  • Plus Jakarta Sans pour tous les headings H1→H3, KPI metrics, noms propres mis en avant
  • Inter pour tout le texte de lecture longue et tous les labels UI
  • JetBrains Mono exclusivement pour IDs, codes, tokens et valeurs numériques techniques
  • Respecter la hiérarchie : jamais un text-sm plus grand qu'un display-sm dans le même contexte
  • Interlignage 1.5+ obligatoire dès que le texte dépasse une ligne
  • Poids 800 réservé aux niveaux display-2xl et display-xl uniquement
  • Toujours tester la lisibilité des deux thèmes avant de valider un choix typographique
  • letter-spacing -0.8px à -0.2px sur les grandes tailles display uniquement
